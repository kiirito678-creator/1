# MyPortal

A single-page student portal (login → dashboard, schedule, grades, events, messages).

## Run it

Just open `index.html` in a browser — no build step, no dependencies to install.

## Publish with GitHub Pages

1. Create a new repository and upload `index.html` (and this `README.md`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then **Save**.
5. Wait ~1 minute. Your site will be live at:
   `https://<your-username>.github.io/<repository-name>/`
